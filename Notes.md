# NULLVEIL — Research Notes

## Operational Security Basics

- Always separate identities. Never mix personal and research accounts.
- Prefer Tor Browser for all research-related activity.
- Minimize metadata: no real name, no real location, no personal photos.
- Use unique passwords + 2FA everywhere (preferably hardware or TOTP).
- Never reuse usernames across different threat models.
