# NULLVEIL — Operational Security

## Core Principles

- Separate identities completely. Never mix personal and research activity.
- Assume every device and network can be compromised.
- Minimize data. If you don’t need it — don’t create it.
- Prefer anonymity tools (Tor, Whonix) for all research-related work.
- Never reuse usernames, passwords, or email addresses across different threat models.

## Account Hygiene

- One identity = one set of accounts.
- Use unique strong passwords + 2FA (TOTP or hardware key) everywhere.
- Avoid phone numbers linked to your real identity.
- Prefer privacy-focused email (Proton, Tutanota) created over Tor.

## Browser & Network

- Use Tor Browser for research.
- Disable JavaScript when possible for high-risk activities.
- Avoid logging into personal accounts while using research identity.
- Prefer Whonix or similar isolated environments.

## Device Security

- Keep systems updated.
- Use full-disk encryption.
- Avoid installing unnecessary software.
- Prefer open-source tools when possible.

## Compartmentalization

- Different threat models require different environments.
- Do not use the same browser profile, VM, or account for unrelated activities.
- Treat each project as a separate compartment.

## Publishing

- Never include personal information in public repositories or posts.
- Review all files for metadata before publishing.
- Use clear, neutral language. Avoid emotional or personal statements.
